# Документация — DESIGN.md

Отдельный файл `DESIGN.md` в корне репозитория.

## Что отражено в документе

**Отмена устаревших запросов.** Реализована через `AbortController`, отмена происходит на каждое изменение ввода (а не только при срабатывании `debounce`). В `searchCountries.ts` сигнал комбинируется с таймаутом через `AbortSignal.any`. Обосновано, почему это лучше флага «актуальный ли ответ»: флаг не прерывает сетевой запрос и не гарантирует, что устаревший результат не дойдёт до рендера, тогда как `AbortController` реально отменяет `fetch`.

**Задержка debounce — 500 мс.** Компромисс: «проглатывает» быстрый набор (~200–300 мс на символ), но не создаёт заметной задержки. Без `debounce` — запрос на каждый символ (6 запросов на «Москва»), лишняя нагрузка и мигание загрузки. При 2000 мс — субъективно медленно, таймер сбрасывается при каждом символе.

**Сложность (Big O).**

- `mapCountryResponse` — O(n × m) по времени и памяти (n — страны, m — языки/валюты), на практике O(n).
- Кэш — O(1) на чтение/запись, память O(k × s), k ≤ 5.
- Дедупликация (`inFlight`) — O(1), память O(d), d — число летящих запросов.

**Принципы чистого кода — с указанием файлов/функций.**

- Чистые функции: `mapCountryResponse`, `debounce`, `createCountryCard`.
- SRP: каждый модуль отвечает за одно (таблица «модуль → ответственность → чего не делает»).
- Нет магических чисел: `DELAY = 500`, `TIMEOUT = 5000`, `MAX_HISTORY = 5`.
- Обработка ошибок без «глотания»: `catch` различает `AbortError`, `TimeoutError`, `HttpError`, остальное.
- Иммутабельность: `mapCountryResponse` не мутирует вход.
- Явные типы TypeScript: `countryResponse` vs `Country`, `signal: AbortSignal`, `init: RequestInit`.
- Тестируемость: фейковые таймеры, мок `fetch` с реакцией на `signal`, mock-данные, deferred-промисы для гонки.

## Чек-лист поведения

- [ ] Отмена предыдущего запроса при каждом изменении ввода (`AbortController`).
- [ ] Комбинирование сигнала отмены с таймаутом 5 с (`AbortSignal.any`).
- [ ] `AbortError` перехватывается отдельно и не показывается пользователю.
- [ ] После `await searchCountries` — проверка `if (signal.aborted) return;` (защита от гонки).
- [ ] `debounce` 500 мс.
- [ ] Спиннер показывается сразу в обработчике `input`, а не после `debounce`.
- [ ] `!response.ok` → `HttpError`; 404 → пустой массив (не ошибка).
- [ ] Кэш ограничен (`MAX_HISTORY = 5`), не растёт бесконечно.
- [ ] Дедупликация одновременных запросов через `inFlight`.
- [ ] Все ветки `catch` обрабатывают ошибку явно, ничего не «глотается» молча.
